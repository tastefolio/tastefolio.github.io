Questions

Does Kestrel read my email?

Messages are scanned automatically in memory and their content is never stored. Logs keep only the sender, time and verdict.

What if an important message is blocked?

Suspicious mail is quarantined, never deleted. Release it in one click and add the sender to your allowlist.

Which mail providers does it work with?

Any provider that supports forwarding or custom MX records.
