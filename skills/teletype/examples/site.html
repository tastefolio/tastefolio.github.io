docs

Four commands. The whole monorepo.

every command ships its own manual: man kiln-cache

kiln-affected(1) kiln manual

name
kiln affected — build only what changed
synopsis
kiln run <task> --affected [--base main]
description
Reads the git diff and the package graph, then runs the task only for changed packages and everything that depends on them.

kiln-cache(1) kiln manual

name
kiln cache — content-addressed remote cache
synopsis
kiln cache [status | push | prune --older 30d]
description
Every task output is stored under the hash of its inputs, so your laptop, CI and teammates read from the same cache.

kiln-watch(1) kiln manual

name
kiln watch — incremental rebuilds on save
synopsis
kiln watch web --open
description
Keeps the graph in memory and rebuilds only the dirty nodes — usually in under 200 ms.

kiln-ci(1) kiln manual

name
kiln ci — automatic sharding across runners
synopsis
kiln ci --affected --shards auto
description
Balances tasks by their real historical run time so every runner finishes at the same moment.

# one file at the repo root
[project]
name         = "acme"
remote_cache = true

[tasks.build]
deps    = ["^build"]
outputs = ["dist/**"]

[tasks.test]
deps    = ["build"]
inputs  = ["src/**", "test/**"]
timeout = 600
# any CI that can run a shell
steps:
  - run: curl -fsSL https://kiln.example/install | sh
  - run: kiln ci --affected --shards auto
    env:
      KILN_TOKEN: $KILN_TOKEN
      KILN_BASE:  origin/main
  • No plugins: tasks are the scripts you already have.
  • "^build" means build dependencies first.
  • Anything outside inputs never busts the cache.

faq

Ask before you install.

Or ask in the community forum — answers usually land within an hour.

Do I have to restructure my repo?

No. kiln reads your existing npm, pnpm or yarn workspaces and only needs one kiln.toml.

Where is my code stored?

Nowhere. Only task outputs are stored, encrypted and keyed by their input hash.

Does it work offline?

Yes — the local cache always works and syncs with the remote cache when you are back.

Can I bring my own runners?

On enterprise, with one command: kiln runner register.
